## 何を見るか（この順に）

### 1. ★ 事実と式・数値の正しさ（最優先）

- **式・数値は自分で検算する。**例題は Python で計算し直す（`iapws`・`CoolProp` が無ければ `pip install` してよい）
- **物性値・係数を地の文で断定していないか**（例題の値は問題文で与える形になっているか）
- **「実在の値ではない」と書いた表に、実在の値が混ざっていないか**
- **法令の数値は台帳と、さらに条文と突き合わせる。**台帳に無い数値が本文にあれば、それ自体が指摘対象
- **法令で外しやすいのは数値ではなく、その周り**：

| 型 | 確かめ方 |
| --- | --- |
| **主体** | 届け出る先・選任する者・承認する者。**兼任の承認は 4 役とも経済産業大臣（1 つの局の管轄内なら局長）**で、台帳の初版はここを外した |
| **除外・限定・ただし書** | 「〜を除く」「〜に限る」。則 4 条のただし書は、燃料と電気は非化石のものだけ、他人から供給された熱は全部 |
| **括弧書きの読み替え** | 「第〇条において同じ」が離れた条の語の意味を変える（則 8 条 5 項 → 則 13 条） |
| **基準日** | 令和 8 年 4 月 1 日時点で施行されている版か。改正の年と施行の年を取り違えていないか |
| **条番号** | 法・令・則の取り違え、項と号の取り違え |

### 2. ★ 条件の書き落とし（いちばん多い型）

**記述を単独で読んで、正しいと言い切れるか。**

- 「理想気体では」「定常で分岐・漏えい・蓄積なし」「摩擦係数一定なら」「両流体とも温度が変化する場合」「同じ管・同じ流体で」
- **比べ方を書いているか**（同じ圧力比か同じ終状態か、同じ流量か同じ熱量か）
- **どちらの基準か**：高発熱量／低発熱量、乾き／湿り、体積／質量、ゲージ圧／絶対圧、入熱基準／出熱基準
- **呼び名の揺れ**：流出係数 C と流量係数 α、温度効率と有効度

### 3. ★ 本番で問われたのに書かれていない

**`public-questions.md` の要約だけでは見えません。問題用紙と標準解答の空欄の中身まで照らすこと。**
課目Ⅲのレビューでは【中】10 件のうち 8 件がこの型でした（分析計の干渉成分、ヘンペル、自然通風の炉内負圧、
大気圧式バーナ、水素の燃焼速度の極大の位置、比重 15/4 ℃、流動層の N₂O）。

- 令和 6〜8 年度の担当の大問の**空欄に入る語・数値**が、その節で説明されているか
- 記号・呼び名が問題文と食い違って、本番で読み替えられないおそれはないか

### 4. ★ 問題文に近すぎないか（公開問題 ©ECCJ の複製）

**書き手に問題用紙を見せると、問題文の並び・例示・場面まで写ります**（課目Ⅳの 4 章は 3 回組み直した）。

- **本文**：問題文と同じ順に同じ事柄を並べていないか。例示・場面・部材の並びが同じでないか
- **★ 試験のポイント・よくある勘違い・まとめ・一問一答**：**空欄の正答が出題順に並んでいないか。**
  一問一答が空欄をそのまま問いにしていないか。**最後まで残ったのはここ**
- **例題の数値の組・場面が本番と同じでないか**
- **§7 の「誤」の記述を、正しい説明として書いていないか**
- **語尾を変えた・一文を分けた・表に並べ替えただけ**は、離れたことになりません。指摘するときは、どの年度・どの大問のどの部分に近いかを書く

### 5. 1 つの主張の居場所どうしの食い違い

**1 つの主張は、1 つの節の中に 6 つの居場所を持ちます。**

```
本文 ／ 表 ／ 試験のポイント ／ よくある勘違い ／ この節のまとめ ／ 一問一答
```

**さらにその外側に、ほかの章・確認問題・計算ドリル・体験ウィジェット・執筆プロンプトがあります。**
`node scripts/echoes.mjs <語>` が居場所つきで出します。

- **章どうしの食い違い**：並行して書かせた章は、互いを見ていません。
  実例：燃焼計算の章が「O₂ 計はふつう乾き」、燃焼装置の章が「ジルコニア式は湿り」と書いていた
- **課目をまたぐテーマ**（`section-plan.md` §3）：**本体でない側に同じ説明を書き直していないか**、置き場所どおりか

### 6. 記法と節の骨格

- `npm run dump <節 id>` で画面の文字を抜き取る（**dump は `**` `::` ``` しか見ないので、数式の中は目で読む**）
- 「# ざっくり言うと」「# この節のまとめ」、「> **試験のポイント**」「> **よくある勘違い**」があるか。一問一答が 5 問以上か
- **画面の字数が 2,500〜4,000 字か**（4,000 字超は止めない目安。2,500 字を切るのは指摘する）
- **flow 図の行頭の `->`**、節の題のバッククォート、強調の閉じ忘れ、箇条が 1 行につながったもの（どれも `check-source.mjs` が弾く型）

### 7. 読者に届いているか

読者は**工場・ビルでエネルギーの管理に携わる技術者**です（`00-common.md` §2）。

- 現場で毎日使う語を、定義から立ち上げ直していないか
- 逆に、法令用語・学術用語をその場で定義せずに使っていないか
- 本番の空欄を埋めるのに足りない深さ・試験に出ない話に割いた紙幅

## 報告の形

**指摘は、次の形で 1 件ずつ書いてください。**

```
### 【重さ】 節 ID（ファイル:行）— 一行の要約

- **いまの記述**：（そのまま引用）
- **何が問題か**：（検算した数値、照らした条文・年度の大問）
- **正しくは**：
- **同じ主張のほかの居場所**：（本文・表・ポイント・勘違い・まとめ・一問一答・ほかの章・プロンプト）
```

| 重さ | 何か |
| --- | --- |
| **重** | **事実が違う。**数値、式、適用範囲、主体、条番号。確認問題にすると「誤答が実は正しい」が起きる |
| **中** | 条件の書き落とし、問われたのに書かれていない、問題文に近すぎる、居場所どうしの食い違い |
| **軽** | 書式、言い回し、冗長 |

**最後に、次の 4 つを必ず書いてください。**

1. **確かめて食い違いが無かった項目**（検算した数値の一覧）
2. **資料からは確かめられなかった項目**
3. **書き手が「自信がない」と挙げた点への判定**（報告を渡されたとき）
4. **★ あなたが自信を持てない指摘**（「違う気がするが根拠が薄い」もの）

**4 が空の報告は受け付けません。**
