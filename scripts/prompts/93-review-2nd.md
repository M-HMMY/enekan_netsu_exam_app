# 2 巡目 — 直したところだけを見る

**1 巡目の指摘を反映したあとに掛けるレビューです。**
**このひな形は 2026 年 9 月 20 日に足しました。**

**なぜ要るか。**[docs/handover.md](../../docs/handover.md) §4 に実績があります。
姉妹アプリ `kikenbutsu_kou_exam_app` で 2 巡目を回したところ、
**1 巡目の修正そのものが新しい誤りを作っていた箇所**が見つかりました。
「無機過酸化物」を「アルカリ金属の過酸化物等」に直したはずが、
**消火の説明では元の広い言い方に戻っていた**、という型です。

**このアプリでも、2 巡目の自己確認だけで 4 件出ています。**

| 出たもの | 型 |
| --- | --- |
| 確認問題が教本にない語（酸素供給源）で書かれていた | **直した先の語が、教本の語と違う** |
| 確認問題に「溶体化処理した状態の」と書いたが、その節にこの語が無い | **裏付けのない語を足した** |
| 「2,300 より大きければ乱流」を直したのに、例題が「5,000 は 2,300 より大きいので乱流」のまま | **直し漏れ** |
| 爆発範囲の中点＝燃焼速度最大を 1 か所で消したが、別のウィジェットに残っていた | **同じ主張の別の居場所** |

**1 巡目とは見るところが違います。**「全体が正しいか」ではなく、
**「この変更が、何かを壊していないか」**を見てください。

**`--sandbox read-only` で走らせてください。**指摘だけさせて、直すのは依頼した側です。

## 何を見るか（この順に）

### 1. ★ その変更が、新しい誤りを作っていないか（最優先）

**足した条件が、別の正しいことを否定していないか。**

- 「理想気体なら」と限定したせいで、実在気体でも成り立つ話まで狭めていないか
- 「原則として」と付けたせいで、例外がないものまで曖昧にしていないか
- **足した文が、同じ節の別の段落と矛盾していないか**

### 2. ★ 直し漏れ — 同じ主張の別の居場所

**これがいちばん多く出ます。**2026 年 9 月 20 日の 2 巡目では、**19 件の指摘のうち 14 件がこの型**でした。

**★ 1 つの主張は、1 つの節の中に 6 つの居場所を持ちます。**

```
本文 ／ 表 ／ 試験のポイント ／ よくある勘違い ／ この節のまとめ ／ 一問一答
```

**さらにその外側に、確認問題・計算ドリル・体験ウィジェット・画面の文言・執筆プロンプトがあります。**
**執筆プロンプトを直し忘れると、書き直したときに同じ誤りが戻ります。**

**数える道具があります。**

```
node scripts/echoes.mjs 安全率          … その語がどこに何回あるかを、居場所つきで出す
node scripts/echoes.mjs 爆発範囲 まん中  … すべてを含む行だけ
node scripts/terms.mjs                  … 確認問題が使っていて、教本に無い語を挙げる
```

- **直した語・数値・言い回しが、そのファイルの中に何か所あるか数えること。**
  本文・表・図・**「試験のポイント」・「よくある勘違い」・「この節のまとめ」・一問一答**は別々の文字列です
- **例題の途中の言い回し**が、直した判定基準と食い違っていないか
- **ほかのファイル**（確認問題、ドリル、ウィジェット、画面の文言）に、同じ主張が残っていないか
- **姉妹の科目**（`ho-` と `gk-`／`gm-`）に、同じ主張が残っていないか

### 3. ★ 確認問題を直した場合

- **`answer` が、直した後の記述の正誤と合っているか**
- **解説の「イは誤り」「ロとハは正しい」が、直した後の記述と合っているか**
- **選択肢の組合せの中に、直した後の正解が実際にあるか**
- **足した記述が、その問の `sectionId` の節に裏付けを持っているか。**
  **教本が使っていない語を、確認問題に持ち込んでいないか**
- 記述の長さが不ぞろいになり、**読まずに選べる**ようになっていないか

### 4. ★ 教本を直した場合

- **節の字数**が 2,500〜4,000 字の範囲から外れていないか
- **`compare` の要素数が偶数**のままか、**`matrix` が 4 セル以下**のままか
- **`**` の開きと閉じが同じ行にある**か
- **張ったリンクの節 ID が実在する**か
- 足した内容が、**その節の担当範囲**（`scripts/prompts/00-common.md` の表）を越えていないか

### 5. ★ 指摘を採らなかった判断が妥当か

**1 巡目の指摘のうち、依頼した側が採らなかったものがあります。**
その理由がコミットメッセージに書いてあれば、**その理由が成り立つか**を見てください。

## 報告の形

```
### 【重さ】 対象 — 一行の要約

- **どう直したか**：（差分のどの行か）
- **何が問題か**：（★ 新しい誤りか、直し漏れか、どちらかを明示する）
- **正しくは**：
- **根拠**：（条・項・号、または一次資料、またはファイル名と行）
```

| 重さ | 何か |
| --- | --- |
| **重** | **直したことで新しい誤りができた。**または、直した主張と正面から矛盾する記述が残っている |
| **中** | 直し漏れ。1 か所だけ古い言い方が残っている |
| **軽** | 言い回し、長さ、リンク |

**最後に、次の 4 つを必ず書いてください。**

1. **差分のすべての変更を見たか**（見ていないものは挙げる）
2. **確かめたが問題が無かった変更**
3. **資料からは確かめられなかったもの**
4. **★ あなたが自信を持てない指摘**

**「1 巡目の修正はすべて妥当です」だけの報告は受け付けません。**
**4 が空の報告も受け付けません。**
