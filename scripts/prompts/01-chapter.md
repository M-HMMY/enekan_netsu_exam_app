# 章を書かせるプロンプトの本体

**章ごとのファイル（`02-…` 以降）は、この文書と `00-common.md` を読ませたうえで、
その章だけの表と釘を渡します。**この文書に共通の手順が書いてあります。

**章ごとのファイルだけを渡さないでください。**下の 3 本をこの順に読ませること。

1. `CLAUDE.md`
2. `scripts/prompts/00-common.md`
3. `scripts/prompts/01-chapter.md`（この文書）
4. `scripts/prompts/【章の番号】-【章 ID】.md`（担当章の指示）

---

## 手順

### 1. 読む

| ファイル | 何のために |
| --- | --- |
| `CLAUDE.md` | このアプリの前提。とくに「読者を誰に置くか」 |
| `scripts/prompts/00-common.md` | 記法・節の骨格・リンクしてよい節 ID・名指しの釘 |
| **`src/data/textbook/intro.ts`** | **★ 文体の見本。**書き始める前に 4 節とも読むこと |
| `docs/primary-numbers.md` | **数値の台帳。ここに無い数値を書かないこと** |
| `docs/syllabus.md` | 出題範囲 |
| `docs/public-questions.md` | 令和 7 年度に実際に問われた形 |
| `docs/section-plan.md` | 節の割り方。**科目をまたいで重なる節の表**も見ること |
| `src/types.ts` | `TextbookSection` の型 |

**★ `src/data/textbook/intro.ts` は必ず読んでください。**
**文体・密度・表の使い方・一問一答の書き方を、そこに合わせます。**

### 2. 条文に当たる

**★ その前に。公開問題の記述を材料に使うなら、正解番号と突き合わせること。**

**設問はすべて「正しいものはどれか」です。**
つまり**イ・ロ・ハ（・ニ）のうち 2〜3 つは誤りの記述**です。
**「令和 7 年度に出ていた」だけでは、正しい側か誤りの側かは決まりません。**

**★ この釘は、実際に踏んだから書いてあります。**
章のプロンプトを書くときに照合を飛ばし、**誤りの記述を 6 か所、
正しいものとして書いてしまいました**（9 つめ・2026 年 9 月 20 日）。

| そのとき書きかけたもの | 実際 |
| --- | --- |
| 9 % ニッケル鋼もアルミニウム合金と同様に −250 ℃ まで使える | **誤りの側**（甲化保 問 3 ロ） |
| フェライト系ステンレス鋼も塩素イオンで応力腐食割れしやすい | **誤りの側**（同 問 3 ニ） |
| 並列冗長系は、故障したら待機機へ切り替える方式 | **誤りの側**（同 問 4 ロ） |
| 段圧が下がる原因は後段の弁の漏れ | **誤りの側**（同 問 6 ロ） |
| ピンホールの漏えい量は孔径の 2 乗に比例 | **誤りの側**（同 問 8 イ） |
| What-if は複数の事象の組合せを想定できない | **誤りの側**（同 問 9 ハ） |

**どれも、もっともらしく読めます。**試験がそう作ってあるからです。

**照合のしかた。**`docs/public-questions.md` §6 に正解番号があります。
問題用紙の選択肢（`(3) ハ、ニ` のような組合せ）と突き合わせれば、
**どの記述が正しくて、どれが誤りだったか**が確定します。

**★ 章のプロンプトに書いてある記述にも、この照合は済んでいます。**
「**誤りの側**で出ました」と書いてあるものを、正しいものとして書かないでください。

---


**担当章の主な条文は、章ごとのファイルに書いてあります。**

- **e-Gov 法令検索**（<https://laws.e-gov.go.jp/>）で条文を確かめてください
- **★ 容器保安規則だけは基準日版を使うこと。**
  現行条文には**令和 8 年 4 月 1 日に存在しない定数**があります。
  版の固定のしかたは `docs/primary-numbers.md` §0
- **台帳に無い数値が必要になったら、書かずに報告してください**

### 3. 書く

**`src/data/textbook/【章 ID】.ts` だけ**を書いてください。
**他のファイルは絶対に変更しないでください。**

```ts
import type { TextbookSection } from '../../types';

export const 【章 ID をキャメルケースにしたもの】: TextbookSection[] = [
  {
    id: 'lw-1',
    categoryId: 'law-what',
    title: '…',
    goal: '…',
    minutes: 12,
    body: `
# ざっくり言うと

…
`,
  },
];
```

- **`id` と `title` は、章ごとのファイルで渡したものをそのまま使うこと。**
  **勝手な ID を作らないでください**
- **`goal` は「〜できる」で終わる 1 文。**一覧に出ます
- **`minutes` は 10〜15**
- **`body` の先頭は改行から**（テンプレートリテラルの書き出し）

### 4. 報告する

`00-common.md` §11 の形で報告してください。

## 節の骨格（**崩すと直前チェックシートに載りません**）

```
# ざっくり言うと          ← 日常語で「何の話か」。2〜4 段落
（本論。見出し・表・図）
> **試験のポイント** …     ← 1 節に 1〜2 個
> **よくある勘違い** …     ← 1 節に 1〜2 個
# この節のまとめ           ← 箇条書き 5〜6 個
```quiz                    ← 一問一答。5 問以上
問い :: 答え
```
```

**「# ざっくり言うと」「# この節のまとめ」「> **試験のポイント**」
「> **よくある勘違い**」は、この文字列そのもので書くこと。**
`src/lib/digest.ts` が機械的に抜き出します。**崩すと黙って拾われません。**

## ★ 「ざっくり言うと」の書き方

**ここが読まれるかどうかを決めます。**

- **日常語で書く。**法令用語をここで使わない
- **読者の現場の経験に接ぎ木する。**
  「現場では〜していますね。法令はそれを〜と呼びます」
- **この節を読むと何が分かるようになるかを、1 文で言う**
- **2〜4 段落。**長くしない

**悪い例**（定義から始めている）。

> 高圧ガス保安法第 2 条は、高圧ガスを 4 つの号に分けて定義しています。第一号は圧縮ガスで…

**良い例**（現場から入る）。

> 現場では「ボンベ」と言いますが、法令はこれをすべて「容器」と呼びます。
> 呼び方が違うだけなら覚え直せば済みますが、**この試験では、そこが答えの分かれ目になります。**

---

## ★ 「よくある勘違い」の作り方

**読者は「ガスを扱う事業所で 2〜5 年働いている人」です。**
**いちばん危ないのは「知らないこと」ではなく「知っているつもり」です。**

**次の 3 つの型から作ってください。**

| 型 | 例 |
| --- | --- |
| **現場の語と法令の語のずれ** | 「ボンベ」と「容器」、「タンク」と「貯槽」、「空ボンベ」と「残ガス容器」 |
| **ガスの性質から規制を推測してしまう** | 「不活性だから緩い」「毒性だから厳しい」… **条文がどう書いてあるかで決まります** |
| **事業所の運用を法令だと思っている** | 「うちではこうしている」… 上乗せのこともあれば、法令が別のことを求めることもある |

## 表を使うところ

**この試験は、表にすると覚えやすいものが多いです。**

- **比較するもの**（第一種製造者と第二種製造者、安全弁と破裂板、保安検査と定期自主検査）
- **数値の一覧**（保安距離、再検査の期間、塗色、爆発範囲）
- **★ ガスの種類で分岐するもの**（この試験の主戦場）

**★ ガスの種類で分岐する表を、法令の章では必ず 1 つ以上入れてください。**
令和 7 年度の法令は、**4 つのガス**（毒性可燃性のアンモニア／可燃性で分解爆発性のアセチレン／
支燃性の酸素／不活性の窒素）を並べて、
**どのガスにこの定めがあり、どのガスに無いか**を問う形が繰り返し出ました。

## 図

**図は自前の実装です。**使えるのは次の 8 種類だけです。

| 種類 | 何に使うか |
| --- | --- |
| `flow` | 手続の流れ（許可 → 完成検査 → 使用開始） |
| `stack` | 積み重なる構造（法 → 政令 → 省令） |
| `tree` | 分類（ガスの分け方、容器の種類） |
| `matrix` | **2 × 2 の 4 セルまで。**5 個目以降は黙って捨てられます |
| `cycle` | 繰り返し（保全のサイクル、PDCA） |
| `seq` | やりとり（届出と受理）。**`A -> B :: 内容` の形。矢印がないと右が消えます** |
| `bits` | ビット列（この試験ではまず使いません） |
| `compare` | 左右の対比。**1 行 1 セル、偶数行が左・奇数行が右。`::` は左右の区切りではありません** |

**★ 図の中で `**強調**` は効きません。**アスタリスクがそのまま出ます。

**無理に図を入れないでください。**表のほうが伝わるなら表にすること。

## 一問一答（quiz）

- **1 節に 5 問以上**
- **答えは言い切る。**「〜など」で濁さない
- **数値と条件を問う。**この試験はそこで決まります
- **「〜とは何か」より「〜はいくつか」「どちらが〜か」**のほうが効きます

**良い例。**

```
圧縮アセチレンガスの定義に出てくる温度は :: 15 度です（ほかの号は 35 度）
許可と届出の境目を決めるのは、貯蔵能力か処理能力か :: 処理能力です
保安検査を行うのは原則として誰か :: 都道府県知事です
```

## ★ やってはいけないこと

1. **公開問題の原文を写さない**（KHK のページに著作権表示があります）
2. **指定されたファイル以外を変更しない**
3. **`npm run check` を実行しない**（並行実行でキャッシュが衝突します）
4. **節 ID を勝手に作らない**
5. **台帳に無い数値を書かない**
6. **「事実に自信がない箇所はありません」と報告しない**
7. **学識の化学と機械で相互にリンクしない**（読者はどちらか一方しか読みません）
8. **bash のヒアドキュメントを使わない**（バックスラッシュを落とします）
