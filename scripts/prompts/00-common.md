## 3. 出題の形（**令和 6〜8 年度の公開問題で確認済み。`docs/public-questions.md`**）

### ★ すべての空欄が、解答群から選ぶ形です

**大問ごとに文章があり、その中に番号付きの空欄が 10〜20 個並びます。空欄ごとに解答群が付き、記号を 1 つマークします。**
令和 8 年度から、数値を桁ごとに塗る欄はなくなりました。

| 空欄の中身 | 解答群の大きさ（令和 6〜8 年度） |
| --- | --- |
| 語句 | 4 前後。2 択もある |
| 式 | 4 前後 |
| 数値 | 5 前後 |
| 記述の組合せ（「①〜③のうち適切なものを全て挙げると」） | 7（①、②、③、①と②、①と③、②と③、①と②と③） |
| 誤った記述を 2 つ選ぶ（課目Ⅲ問題 9 に 3 年連続） | 6 前後。2 空欄で順序は問わない |
| 複数の空欄で共有する語群 | 11 や 20 もあった |

### ★ 空欄はつながっています

**計算の大問では、前の空欄の答えを次の空欄で使います。**式の形を問う空欄 → その式に数値を入れた値 → その値を使った次の量、と続きます。
**だから教本の計算の節は、「式を選ぶ」「値を出す」「次の量につなぐ」の 3 段を、1 つの例で通して見せてください。**

### ★ 電卓と数値の扱い（受験案内。`i-3` に詳しく書いてある）

- **電卓は四則・開平（√）・百分率・メモリまで。関数電卓は使えません**
- **指数・対数が要る問題には、公開問題では表が付いていました。**「打てないから出ない」と書かないこと。「値は表で与えられるので、式を立てられれば解ける」と書く
- **与えられた数値は、書いてある位より下を 0 とみなす。**「√3 ＝ 1.73 とする」のように特記された値はその値を使う（g や π も同じ）
- **計算の途中で丸めない。**解答群から「計算結果に最も近いもの」を選ぶ

### ★ 課目Ⅰ問題 3 は寄せ集めです

判断基準の空欄のあと、**独立した小問が 16〜18 個**並びます（熱・燃焼・流体・電気・照明）。
課目Ⅰの `ea-13`〜`ea-18` は、**課目Ⅱ・Ⅲの節の縮約ではなく、「小問 1 つを数分で解く型」**を書く節です。式の導出は課目Ⅱ・Ⅲの節へリンクしてください。

## 4. 節の骨格（**崩すと直前チェックシートに載りません**）

```
# ざっくり言うと          ← 日常語で「何の話か」。2〜4 段落
（本論。見出し・表・図）
> **試験のポイント** …     ← 覚えるべき事項。1 節に 1〜2 個
> **よくある勘違い** …     ← 先回りして潰す誤解。1 節に 1〜2 個
# この節のまとめ           ← 箇条書き 5〜6 個
```quiz                    ← 一問一答。**5 問以上**
問い :: 答え
```
```

- **「# ざっくり言うと」「# この節のまとめ」は、この文字列そのもの**で書くこと
- **「> **試験のポイント**」「> **よくある勘違い**」も、この形**で書くこと
- `src/lib/digest.ts` がこの 3 つを機械的に抜き出し、**直前チェックシート**に並べます
- **書式を崩すと、黙って拾われません。**エラーにもなりません

### 一問一答（quiz）

- **1 節に 5 問以上。**`npm run check` が 4 問未満を警告します
- 答えは**言い切る**こと。「〜など」で濁さない
- **「〜とは何か」より「〜はいくつか」「どちらが〜か」「何に比例するか」**のほうが効きます

### ★★ 計算の骨組みは、「代入」と「単位付きの値」まで書くこと

**その節が本番で計算として問われるなら、骨組みを必ず 1 つ置いてください。**「この節は説明が中心だから」と省かないこと。

| 段 | 書くもの |
| --- | --- |
| 1 | **与えられた条件を記号と単位つきで並べる** |
| 2 | **よりどころの式と、その根拠**（どの法則・収支から来るか） |
| 3 | **立式と変形** |
| 4 | **★ 代入**（値を入れた 1 行） |
| 5 | **★ 単位付きの値** |
| 6 | **解答群での確かめ**（桁がそろうか、どの選択肢にも近くなければ前の段を疑う） |
| 7 | **次の空欄へのつなぎ**（この値を次に何に使うか） |

**★ 系譜で落ちたのは 4 と 5 です**（高圧ガス甲種版で 5 つの節が「式の形まで」で止まっていた）。
**本番は数値の空欄が多いので、式の形が出ても値まで行かなければ点になりません。**

**説明のために値を置くのは構いません。**ただし**公開問題の数値は使わないこと**（省エネルギーセンターが無断の複製・転写を禁じています）。**こちらで作った値にしてください。**

### 1 節の大きさ

**10〜15 分（`minutes`）。**本文は **2,500〜4,000 字**が目安です。
**2,000 字未満の節は `npm run check` が警告します。**2,000 は床であって目安ではありません。

**★★ 節数の多い章ほど、1 節あたりが薄くなります**（系譜で 2 例。11 節の章が 800〜1,500 字で返ってきた）。
**書き終えたら報告の前に、節ごとの字数を自分で数えてください。**

- **2,500 字に届かない節があるなら、その節 id を名指しして、理由を書くこと**
- **数えずに「目安に収まっています」と書かないこと**
- **節が 7 本以上ある章では、とくに気をつけてください**（`k1-tech` は 17 節、`k2-gas` は 10 節）

## 5. 記法（**Markdown のサブセットです。自前の実装です**）

### 使えるもの

- 見出し `#`〜`####`
- 箇条書き `-` と番号付き `1.`（**入れ子は 1 段まで**）
- 表 `| a | b |`
- 強調 `**…**`、コード `` `…` ``
- 数式 `$…$` と ```` ```math ````
- リンク `[ラベル](textbook/節 ID)`、`[ラベル](sheet)` など
- 図 ```` ```diagram:flow ```` ほか
- 一問一答 ```` ```quiz ````
- 体験ウィジェット ```` ```widget:<id> ````（**章の指示で渡したものだけ**）

### ★ バックスラッシュの落とし穴（**系譜で何度も壊しています**）

本文は **TypeScript のテンプレートリテラル**の中に置きます。

| 書きたいもの | ファイルに書く形 |
| --- | --- |
| 数式の `\frac` | **`\\frac`**（バックスラッシュ 2 つ） |
| `\n` を文字として出す | `\\n` |
| バックティック | バックスラッシュ ＋ バックティック |
| `${` | `\${` |

**★ `$...$` の中のバックスラッシュは、必ず 2 つ重ねてください。**
1 つだと JavaScript が食べてしまい、**`\sum` が `sum` と表示されます。**
**★ 細い空白も 2 つ重ねて `\\,` と書いてください。**1 つ（`\,`）だと JavaScript が食べて、画面に読点が出ます。
（以前は描画部品が `\,` を読点として出していたので `\\ ` を勧めていましたが、2026 年 9 月 30 日に描画部品を直しました。）
**★ アクセントと、添字・上付きに置く命令は中かっこで包むこと。**`\\dot{m}`、`T_{\\infty}`。
中かっこなし（`\\dot m`、`T_\\infty`）は崩れて、生の文字が出ます（`check-source.mjs` が弾きます）。
**★ 数式の中で記号として波かっこを出さないこと**（`\\{` `\\}`）。描画検査が崩れとみなすので、角かっこ `[ ]` を使ってください。

**★ bash のヒアドキュメント（`cat > file <<'EOF'`）を使わないでください。**
**バックスラッシュを勝手に落とします。**ファイルの書き込みには、エディタのツールか Python を使ってください。

### ★★ 数式の書き方は 2 つだけです（**LaTeX をそのまま持ち込まないこと**）

| したいこと | 書き方 |
| --- | --- |
| 文の中に式を入れる | `PV=nRT を $ ではさむ` |
| 式を別行立てにする | ```` ```math ```` のブロック（**開いて、式を書いて、閉じる**） |

**★ 次のものは使えません。**LaTeX では通りますが、このアプリは知りません（系譜で 89 か所出ました）。

| 使えないもの | どうなるか | 代わりに |
| --- | --- | --- |
| ドル記号を 2 つ重ねて囲む書き方 | **ドル記号が地の文に出ます** | ```math ブロック |
| バックスラッシュ ＋ 角かっこ／丸かっこ | **かっこが本文に出ます** | 同上、または文中の数式 |
| `boxed`（枠で囲む命令） | **命令名がそのまま出ます** | 枠で囲まず、本文側で「**答え**」と書く |

**使える命令は `src/lib/mathSymbols.ts` に並んでいます。**
**そこに無い命令を使うと `npm run check` がエラーにします。**どうしても要るなら、**報告に書いてください。**

### ★★ 1 つの数式を、改行で 2 行に分けないこと

**別行立ての数式を、分子と分母で改行したり、等号の前で折り返したりしないでください。**
**1 つの数式は、必ず 1 行に書いてください。**系譜で、この書き方がレンダラの無限再帰を起こしています。

### ★ 強調は行をまたげません

`**` の開きと閉じが別の行にあると、**`**` がそのまま画面に出ます。**

### 図の注意

- **図の中で `**強調**` は効きません。**アスタリスクがそのまま出ます
- **`compare` は「1 行 1 セル、偶数行が左・奇数行が右」。**`::` は左右の区切りではありません
- **`matrix` は 2 × 2 の 4 セルまで。**5 個目以降は**黙って捨てられます**
- `seq` は `A -> B :: 内容` の形。**矢印がないと `::` の右が表示されません**

## 7. ★ 数値は台帳を経由すること

### 法令の数値（`k1-law`・`k1-policy`）

**`docs/primary-numbers.md` に載っている値だけを書いてください。台帳に無い数値は書かないこと。**
`npm run check` が、この 2 章の本文と確認問題の「数値 ＋ 単位」を台帳と照らします。
必要な値が台帳に無ければ、**書かずに報告してください。**

**★ いま台帳に無いもの**：告示（工場等判断基準の年平均 1 % や工業炉の基準値など）と、エネルギー白書の数値。
**これらを使う節（`ea-6`・`ea-9`〜`ea-12`・`hu-43`）では、数値を書かずに構造だけを書き、報告に挙げてください。**

### 工学の数値（課目Ⅰ問題 3 と課目Ⅱ〜Ⅳ）

台帳の担当ではありません。**物性値や代表的な値は、問題文が与える値を使うのが本番の形**です。
教本で値を置くときは、**「説明のために置いた値で、本番は問題文の値を使う」と添えてください。**

### ★ 数値が合っていても、その周りで落とします

**台帳を作ったとき、codex の検算で数値の誤りは 0 件、指摘 17 件はすべて除外・限定・ただし書と起点の書き落としでした**（2026 年 9 月 30 日）。

| 型 | この試験での例 |
| --- | --- |
| **除外を落とす** | 特定事業者から**連鎖化事業者・認定管理統括事業者・管理関係事業者を除く**（法 7 条 1 項） |
| **適用単位を落とす** | 管理者は「第一種指定工場等ごと」で、しかも**5 業種の工場等（事務所の用途を除く）だけ**（法 11 条、令 5 条） |
| **ただし書の有無を揃えてしまう** | 選任期限の災害等のただし書は、**企画推進者と管理員にはあり、管理者には無い**（則 13・17・23 条） |
| **起点を取り違える** | 資質向上講習の 3 年は、受講日ではなく**受講日の属する年度の翌年度の開始の日から起算**（則 14・32 条） |
| **主体を取り違える** | 合理化の判断基準は**主務大臣**、非化石転換の判断基準は**経済産業大臣**（法 5 条 1・2 項） |
| **2 つの制度を 1 行にまとめる** | 中長期計画は合理化の計画と非化石転換の計画の 2 つ。**提出頻度を減らせる条件も別**（則 35 条 2・3 項） |

**一行で書こうとすると、必ずどれかが落ちます。**
**「〜を除く」「〜に限る」「どの条の話か」「誰が行うか」を、数値と同じ重さで確かめてください。**

### 条番号の書き方

- 条番号を書くなら、**必ず台帳か条文に当たって確かめること**
- **要件を引用するなら、要件を全部並べること。**1 つ落とすと、誤答が正答になります
- 迷ったら**条番号を書かない**ほうが安全です。**間違った条番号は、正しい説明より害があります**

## 8. 名指しの釘（**この試験で実際に外しやすいところ**）

**姉妹アプリでは、名指しした箇所は全章で正しく書けていました。**

1. **原油換算は 1 GJ ＝ 原油 0.0258 kL。**電気は**自家発・特定需要家向けの非化石電気が 3.60、それ以外が 8.64 GJ/千 kWh**。他人から供給された熱は**熱の種類ごとの係数**（産業用蒸気 1.17、それ以外 1.19）
2. **資格の書き方が 3 通り。**管理者＝**免状**。企画推進者・管理員＝**講習の修了者か免状**。統括者＝**事業の実施を統括管理する者**（免状は要件でない）
3. **管理者の人数は前年度の使用量で決まる。**コークス製造業・電気供給業・ガス供給業・熱供給業は 100,000 kL で 1 人と 2 人に分かれ、それ以外は 20,000・50,000・100,000 kL で 1〜4 人
4. **選任の期限。**統括者は「遅滞なく」、ほかの 3 役は 6 月以内。**届出は 4 役とも選任・解任の日後の最初の 7 月末日まで**
5. **公開問題で「誤」だった記述**（`docs/public-questions.md` §7）を正しい説明として書かないこと。とくに：
   - アシッドスマットが吸着しているのは**硫酸**（塩酸ではない）
   - **拡散燃焼は逆火しない**（逆火は予混合の問題）。**完全予混合の火炎は不輝炎**
   - 水蒸気を噴霧媒体にするのは**高圧気流式**
   - 旋回羽根で旋回を与えるのは**スワラ**（バッフルは遮蔽物の後流を使う）
   - 流動層に供給して SOx を固定するのは**石灰石**（石膏は生成物）
   - 燃焼域の空気流速は、火格子・流動層・微粉炭のうち**火格子が最も小さい**
6. **状態方程式・放射・カルノー効率には絶対温度。**温度差だけなら ℃ と K で同じ値
7. **特記された値を使う。**「√3 ＝ 1.73」「g ＝ 9.8」と問題にあれば、その値で計算する
8. **判断基準の数値（工業炉の基準空気比など）は `hu-43` にだけ書く**（課目Ⅰと課目Ⅳで同じ値を 2 か所に書かない）

## 9. 書き方の作法

### 文体

- **常体ではなく敬体**（「です・ます」）で書いてください
- **1 文を短く。**主語と述語を近づける
- **「〜と思われます」「〜のようです」を使わない。**言い切るか、書かないか
- **箇条書きに逃げない。**理由と因果は文で書く
- **仕組みと因果から書く。**「〜と覚えましょう」で終わらせない
- **★ 文体の見本は `src/data/textbook/intro.ts`。**書き始める前に 4 節とも読むこと

### 表を使うところ

- **比較するもの**（第一種と第二種の指定工場等、4 つの役、拡散燃焼と予混合燃焼、丸ボイラと水管ボイラ）
- **数値の一覧**（閾値、選任の人数、換算係数）
- **状態変化の一覧**（等圧・等容・等温・断熱で、仕事・熱量・ΔU がどうなるか）

### 時点を書く

- 法令は**「令和 8 年 4 月 1 日時点」**と本文に書いてください。試験の基準日です
- 統計や政策の数値は、**資料の名前・年版・年度**を必ず添えてください（例：エネルギー白書の何年版の何年度実績）

## 10. やってはいけないこと

1. **公開問題の原文を写さないこと。**省エネルギーセンターの過去問ページに、**無断での複製・転写を禁じる**と書いてあります。
   **語尾を変える・条件句を削る・一文を分けるだけでは、書き起こしたことになりません。**仕組みや因果から、別の構成で書いてください。
   公開問題の事例（事業者の設定、燃料の組成、サイクルの条件）も、**数値と場面を自前で作ること**
2. **指定されたファイル以外を変更しないこと**
3. **`npm run check` を実行しないこと。**複数の章を並行で書くので、キャッシュが衝突します。**検査は依頼した側がまとめて 1 回**行います
4. **節 ID を勝手に作らないこと。**§6 の表と、章の指示で渡した ID だけを使ってください
5. **「事実に自信がない箇所はありません」と報告しないこと。**自信がない箇所は必ず挙げてください

## 11. 報告の形

書き終えたら、次を報告してください。

1. **書いた節の一覧**（ID と字数）
2. **台帳（`docs/primary-numbers.md`）に無くて書けなかった数値**
3. **★ 自信がない箇所**（条番号、適用範囲、用語の定義、式の適用条件、課目の線引き）
4. **他の章に書くべきだと思った内容**（`docs/section-plan.md` §3 の置き場所と食い違うもの）

**3 が空の報告は受け付けません。**必ず 1 つ以上挙げてください。
