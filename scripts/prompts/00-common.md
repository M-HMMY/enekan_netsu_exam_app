### ★ 学識は記述式です

**答え方は 7 種類ありました**（`docs/public-questions.md` §3）。

| 答え方 | 例 |
| --- | --- |
| **計算（根拠と計算式を示す）** | 総括伝熱係数、伝熱管長さ、モル分率、TNT 換算 |
| **式を立てる／導く** | 反応速度式、ベルヌーイの式、力の釣合い式 |
| **式を積分して関係式を示す** | 2 次反応の積分形 |
| **論述** | 連鎖反応、引火点、クリープ現象、沸点の変化 |
| **図を描く** | クリープ曲線（軸名・3 段階・破断点） |
| **穴埋め** | 元素記号、脆化の呼び名 |
| **表を埋める** | 物質の性質・用途・工業的製造法 |

**★ だから学識の節には、「記述式で書かされる形」を必ず 1 つ入れてください。**

- **式がどこから来るか**（力の釣合い、エネルギー保存、物質収支）
- **式を立てる手順**（何を置き、どの式を連立し、何を消すか）
- **答えの検算**（単位が合うか、桁が現実的か、極限で妥当か）

**1 を飛ばして 2 だけ書くと、記述式では点になりません。**
令和 7 年度の甲種機械 問 4（薄肉球形胴）は、
**「投影面積を D で表せ」「接線応力が作用する面積を D と t で表せ」「力の釣合い式を示せ」**と、
**導出の各段階を順に書かせて**います。

### ★ 電卓の制約と、その本当の意味

**電卓は四則計算のみ。**関数電卓は禁止で、**開平計算は使えます**（受験案内書 Ⅲ-3-③）。

**★ だからといって「対数や指数は出ない」ではありません。**
**問題文が値を表で与えます。**令和 7 年度の甲種機械 問 5 では、
`ln 2 = 0.693`、`5^(1/3) = 1.710` のような表が付いていました。

**教本で「電卓で打てないから出ない」と書かないこと。**
**「値は問題文が与えるので、式を立てられれば解ける」**と書いてください。

## 4. 節の骨格（**崩すと直前チェックシートに載りません**）

```
# ざっくり言うと          ← 日常語で「何の話か」。2〜4 段落
（本論。見出し・表・図）
> **試験のポイント** …     ← 覚えるべき事項。1 節に 1〜2 個
> **よくある勘違い** …     ← 先回りして潰す誤解。1 節に 1〜2 個
# この節のまとめ           ← 箇条書き 5〜6 個
```quiz                    ← 一問一答。**5 問以上**
問い :: 答え
```
```

- **「# ざっくり言うと」「# この節のまとめ」は、この文字列そのもの**で書くこと
- **「> **試験のポイント**」「> **よくある勘違い**」も、この形**で書くこと
- `src/lib/digest.ts` がこの 3 つを機械的に抜き出し、**直前チェックシート**に並べます
- **書式を崩すと、黙って拾われません。**エラーにもなりません

### 一問一答（quiz）

- **1 節に 5 問以上。**`npm run check` が 4 問未満を警告します
- **この試験は数値と条件を覚えているかで決まります。**保安距離、貯蔵能力、容器再検査の期間、
  爆発範囲、温度の上限。**一問一答が効く試験です**
- 答えは**言い切る**こと。「〜など」で濁さない

### ★★ 答案の骨組みは、「代入」と「単位付きの答え」まで書かせること

**学識の節には「答案の骨組み」を入れる、と章ごとの指示に書いてあります。**
**そこで何をもって完成とするかを、ここで決めておきます。**

| 段 | 書くもの |
| --- | --- |
| 1 | **記号を置く**（何を何と置くか） |
| 2 | **よりどころの式と、その根拠**（どの法則から来るか） |
| 3 | **立式** |
| 4 | **変形** |
| 5 | **★ 代入**（問題文の値を入れた 1 行） |
| 6 | **★ 単位付きの答え**（「**（答）〜**」で結ぶ） |
| 7 | **検算**（単位・桁・極限） |

**★★ 5 と 6 が落ちます。**2026 年 9 月の 2 巡で、**5 つの節が 4 で止まって**いました
（`gk-7`・`gm-4`・`gm-5`・`gm-9`・`gm-19`）。
どれも式の形までは正しく、**「$W=nRT\ln(V_2/V_1)$ まで導きます」で終わって**いました。

**本番は「根拠、計算式を示して答えよ」です。**
**式の形が出ても、代入と単位付きの答えが無ければ、そこの点は入りません。**

**★ 値が無いから書けない、は理由になりません。**
物性値は台帳に無く、本文で決め打ちできませんが、**置換欄の形で最後まで見せられます。**

- 「$W=nRT\ln(V_2/V_1)=(\text{問題文の }n)(\text{問題文の }R)(\text{問題文の }T)(\text{表の値})$」
- 「**（答）$W=$ （数値）J**」

**説明のために値を置くのは構いません。**ただし、
**「この値は手順を見せるために置いたもので、覚える必要はない」と必ず添えてください。**
**公開問題の数値は使わないこと**（KHK の著作物です）。こちらで作った値にします。

### ★ 計算で問われる節に、骨組みが無いことがあります

**「この節は説明が中心だから」と省かないでください。**
令和 7 年度に計算で問われた論点の節（`gm-12` の管摩擦など）で、
**骨組みが 1 つも無いまま返ってきた**ことがあります。

**その節が本番で計算として問われるなら、骨組みを置いてください。**

### 1 節の大きさ

**10〜15 分（`minutes`）。**本文は **2,500〜4,000 字**が目安です。
**2,000 字未満の節は `npm run check` が警告します。**
**★ 警告が出なければよい、ではありません。**2,000 は床であって目安ではありません。
**甲種の保安管理技術は「高度の」**なので、
**2,000 字台で返すつもりなら、なぜそれで足りるかを報告に書いてください。**

**★★ 節数の多い章ほど、1 節あたりが薄くなります**（2026 年 9 月 21 日に 2 例）。

| 章 | 節 | 返ってきた字数 |

## 5. 記法（**Markdown のサブセットです。自前の実装です**）

### 使えるもの

- 見出し `#`〜`####`
- 箇条書き `-` と番号付き `1.`（**入れ子は 1 段まで**）
- 表 `| a | b |`
- 強調 `**…**`、コード `` `…` ``
- 数式 `$…$` と ```` ```math ````
- リンク `[ラベル](textbook/節 ID)`、`[ラベル](sheet)` など
- 図 ```` ```diagram:flow ```` ほか
- 一問一答 ```` ```quiz ````

### ★ バックスラッシュの落とし穴（**系譜で何度も壊しています**）

本文は **TypeScript のテンプレートリテラル**の中に置きます。

| 書きたいもの | ファイルに書く形 |
| --- | --- |
| 数式の `\frac` | **`\\frac`**（バックスラッシュ 2 つ） |
| `\n` を文字として出す | `\\n` |
| バックティック | バックスラッシュ ＋ バックティック |
| `${` | `\${` |

**★ `$...$` の中のバックスラッシュは、必ず 2 つ重ねてください。**
1 つだと JavaScript が食べてしまい、**`\sum` が `sum` と表示されます。**
`npm run check` が検出しますが、**最初から 2 つで書くこと。**

**★ bash のヒアドキュメント（`cat > file <<'EOF'`）を使わないでください。**
**バックスラッシュを勝手に落とします。**ファイルの書き込みには、
エディタのツールか Python を使ってください。

### ★★ 数式の書き方は 2 つだけです（**LaTeX をそのまま持ち込まないこと**）

**このアプリの Markdown は自前の実装です**（`src/lib/markdown.tsx`、`src/lib/math.tsx`）。
**数式の書き方は、次の 2 つしかありません。**

| したいこと | 書き方 |
| --- | --- |
| 文の中に式を入れる | `PV=nRT を $ ではさむ` |
| 式を別行立てにする | ```` ```math ```` のブロック（**開いて、式を書いて、閉じる**） |

**★ 次のものは使えません。**LaTeX では通りますが、このアプリは知りません
（2026 年 9 月 21 日に、学識機械の 4 章で 89 か所出ました）。

| 使えないもの | どうなるか | 代わりに |
| --- | --- | --- |
| ドル記号を 2 つ重ねて囲む書き方 | **ドル記号が地の文に出ます** | ```math ブロック |
| バックスラッシュ ＋ 角かっこ／丸かっこ | **かっこが本文に出ます** | 同上、または文中の数式 |
| `boxed`（枠で囲む命令） | **命令名がそのまま出ます** | 枠で囲まず、本文側で「**答え**」と書く |

**使える命令は `src/lib/mathSymbols.ts` に並んでいます。**
**そこに無い命令を使うと `npm run check` がエラーにします。**
どうしても要るなら、**報告に書いてください**（依頼した側が足すか、書き方を変えます）。

### ★★ 1 つの数式を、改行で 2 行に分けないこと

**別行立ての数式を、分子と分母で改行したり、等号の前で折り返したりしないでください。**
**1 つの数式は、必ず 1 行に書いてください。**

**2026 年 9 月 18 日には、この書き方でレンダラが無限再帰を起こし、
`npm run check` が `Maximum call stack size exceeded` で落ちました**
（`src/lib/math.tsx` の `takeGroup` の注記）。
**9 月 21 日にも、別の章で 9 か所出ています。**

### ★ 強調は行をまたげません

`**` の開きと閉じが別の行にあると、**`**` がそのまま画面に出ます。**
`npm run check` が 1 行の中の `**` の数を数えて弾きます。

### 図の注意

- **図の中で `**強調**` は効きません。**アスタリスクがそのまま出ます
- **`compare` は「1 行 1 セル、偶数行が左・奇数行が右」。**
  **`::` は左右の区切りではありません**（補足です）。要素が奇数だと検査が落ちます
- **`matrix` は 2 × 2 の 4 セルまで。**5 個目以降は**黙って捨てられます**
- `seq` は `A -> B :: 内容` の形。**矢印がないと `::` の右が表示されません**

## 7. ★ 数値は台帳を経由すること

**`docs/primary-numbers.md` に載っている値だけを書いてください。**
**台帳に無い数値は書かないこと。**必要なら、章のプロンプトの報告欄に
「台帳に無いので書けなかった項目」として挙げてください。

**★ 数値が合っていても、その周りで落とします。**
この教本の作成中、**数値は全部合っていたのに、適用範囲と条番号で 7 件**、
**数値をひとつも含まない用語の一行定義で 13 件**外しました。

| 型 | 例 |
| --- | --- |
| **主体を 1 つに決めつける** | 「保安検査は都道府県知事が行う」… **協会・指定保安検査機関・認定保安検査実施者の道がある**（法 35 ①ただし書） |
| **除外を落とす** | 第二種製造者から**冷凍と液石法の供給設備充塡者**が抜けた。第二種保安物件の**同一敷地内を除く**が抜けた |
| **起点を取り違える** | 設備距離を「製造設備から」と書いた。条文は**「貯蔵設備及び処理設備の外面から」**（一般則 6 ①二） |
| **要件を隣の役職から持ってくる** | 保安統括者に「経験の要件がある」と書いた。**経験が要るのは保安技術管理者と保安係員** |
| **2 つの制度を 1 行にまとめる** | 保安主任者と保安企画推進員を「補佐する人」で一括りにした。**補佐する相手も職務も別**（法 32 ④⑤） |
| **量の条件を全体にかける** | 特定高圧ガスを「7 種類を一定数量以上」と書いた。**その 7 つは量に関係なく対象**（令 7） |
| **数値がかかる相手を間違える** | 超低温容器を「常用の温度をマイナス 50 度以下に保つ容器」と書いた。**マイナス 50 度は充塡する液化ガスの温度**（容器則 2 三） |

**一行で書こうとすると、必ずどれかが落ちます。**
**「〜を除く」「〜に限る」「どの条の話か」「誰が行うか」を、数値と同じ重さで確かめてください。**

### 条番号の書き方

- 条番号を書くなら、**必ず条文に当たって確かめること**
- **要件を引用するなら、要件を全部並べること。**1 つ落とすと、誤答が正答になります
- 迷ったら**条番号を書かない**ほうが安全です。**間違った条番号は、正しい説明より害があります**

## 8. 名指しの釘（**この試験で実際に外しやすいところ**）

**姉妹アプリでは、名指しした箇所は全章で正しく書けていました。**

1. **高圧ガスの定義で、圧縮アセチレンだけ温度が 15 度。**ほかの号は 35 度
2. **液化ガスの第三号後半は、いまの圧力を問うていない。**
   いま 0.1 MPa でも、**0.2 MPa になる温度が 35 度以下なら高圧ガス**
3. **法令の「圧力」はゲージ圧力**（法 2 一の括弧書き）。
   **学識の計算式に入れるのは絶対圧力と絶対温度。**この切り替えを毎回書くこと
4. **可燃性ガスの定義は「または」。**
   爆発限界の下限が 10 % 以下、**または**上限と下限の差が 20 % 以上
5. **許可と届出の境目は処理能力**、貯蔵所と保安距離は**貯蔵能力**。混ぜないこと
6. **保安検査は都道府県知事、定期自主検査は事業者自身。**主体が違います
7. **充塡容器と残ガス容器の分かれ目は、充塡時の質量の 2 分の 1。**
   **残ガス容器は「空の容器」ではありません**
8. **第一種設備距離の 0 ≦ X < 10,000 は 12√2 ≒ 16.97 m。**
   **√3 ではありません。**二次情報に 17.32 m と書いているものがあります
9. **「不活性だから規制が緩い」は成り立ちません**（上の窒素の表）
10. **円周応力が軸応力の 2 倍になるのは、薄肉の胴のとき**

## 9. 書き方の作法

### 文体

- **常体ではなく敬体**（「です・ます」）で書いてください
- **1 文を短く。**主語と述語を近づける
- **「〜と思われます」「〜のようです」を使わない。**言い切るか、書かないか
- **箇条書きに逃げない。**理由と関係は文で書く

### 表を使うところ

- **比較するもの**（第一種製造者と第二種製造者、安全弁と破裂板、保安検査と定期自主検査）
- **数値の一覧**（保安距離、再検査の期間、塗色）
- **ガスの種類で分岐するもの**（この試験の主戦場です）

### 時点を書く

改正や改訂があるものは、**「令和 8 年 4 月 1 日現在」のように時点を本文に書いてください。**
試験の基準日がこの日です。

## 10. やってはいけないこと

1. **公開問題の原文を写さないこと。**KHK のページに著作権表示があります。
   **設問の形を真似るのはかまいませんが、文面を写してはいけません**
2. **指定されたファイル以外を変更しないこと。**
   あなたが書き込むのは `src/data/textbook/<章 ID>.ts` だけです
3. **`npm run check` を実行しないこと。**
   複数の章を並行で書くので、キャッシュが衝突します。**検査は依頼した側がまとめて 1 回**行います
4. **節 ID を勝手に作らないこと。**章のプロンプトで渡した ID だけを使ってください
5. **「事実に自信がない箇所はありません」と報告しないこと。**
   **自信がない箇所は必ず挙げてください。**挙げないと、こちらが検算する場所を選べません
