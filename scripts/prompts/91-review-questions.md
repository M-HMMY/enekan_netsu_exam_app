## 何を見るか（この順に）

### 1. ★ 正解が 1 つに定まるか（最優先・いちばん重い）

**問題を 1 問ずつ、自分で解いてください。**解説を読む前に、問題文と前置きだけで。

- **語句の空欄**：誤答の語が、文脈によっては当てはまってしまわないか（同義語、上位の語、条件次第で成り立つ語）
- **比較の空欄**：条件（同じ流量か、同じ熱量か）が書かれていないために、答えが割れないか
- **組合せ・誤り選び**：**記述を 1 つずつ、独立に検証する。**
  **「誤り」とされた記述が本当に誤りか**がいちばん重い。ただし書き・例外条件を落としたせいで、
  **誤答のつもりが実は正しい**という事故が、系譜で繰り返し起きています
- **1 つの記述で 2 つのことを言っていないか**（片方が正しく片方が誤りだと、正誤が定まらない）
- **前置きを使う問題**：前置きと問題文だけで解けるか。**前の問題の答えを前提にしていないか**（前の答えは問題文で与える決まり）。
  前置きに正答がそのまま書かれていないか

**とくに次を疑ってください。**

| 疑うところ | 例 |
| --- | --- |
| **「すべて」「常に」「必ず」** | 本当に例外が無いか。逆に、正しい言い切りまで誤りにしていないか |
| **主体** | 届出先・選任する者・承認する者。経済産業大臣か主務大臣か、局長が入るか |
| **除外・限定・ただし書** | 則 4 条のただし書の範囲、「〜に限る」を落とした記述 |
| **基準** | 高／低発熱量、乾き／湿り、体積／質量、ゲージ／絶対、入熱／出熱 |
| **条件** | 理想気体、定常、可逆、同じ管・同じ流体、両流体とも温度が変化 |

### 2. ★ 計算は必ず検算する

- **答えを Python で計算し直し、正解の選択肢がいちばん近いことを確かめる**
- **途中を丸めたとき（3 桁・2 桁）に、正解が隣の選択肢に移らないか**。選択肢の間隔が丸めの幅より十分大きいか
- **誤答が「ありがちな間違え方」の値になっているか**（℃ のまま、ゲージ圧のまま、高・低発熱量の取り違え、1,000 倍のずれ）。
  **誤答のどれかが、別の妥当な解き方で出る値と一致して、正解が 2 つにならないか**
- **電卓は四則と √ まで。**指数・対数・三角関数の値が要るのに問題文で与えていないものは指摘する
- **有効数字と単位が、選択肢の桁・単位とそろっているか**

### 3. 数値が一次資料と合っているか

- **法令の数値**（問題文・記述・選択肢・解説のすべて）を台帳と、さらに条文と突き合わせる。**誤答側の数値も**、たまたま正しい値になっていないか
- **工学の数値**：物性値・係数は問題文か前置きで与えているか。地の文で断定した値を前提にしていないか

### 4. ★ 公開問題（©ECCJ）を写していないか

**高圧ガス甲種版では、公開問題とほぼ同文の記述が確認問題に系統的に入っていて、公開後に見つかりました。**

- **前置きの設定**（燃料の組成、温度・圧力、事業者の事例、機器の仕様）が本番と同じでないか。**数値の組を使っていないか**
- **問題文・記述**が本番の空欄の文をなぞっていないか。**語尾を変えた・一文を分けた・条件句を削っただけ**は写しとみなす
- **章の問題が、本番の空欄の出題順に並んでいないか**
- **§7 の記述（要旨）を、そのまま ①〜③ の記述に使っていないか**。§7 で「誤」とされた記述を正しい記述にしていないか
- 疑わしい箇所は、**年度・大問・空欄の番号を挙げて**指摘する

### 5. 形（`npm run check` が見ているものと、見ていないもの）

- **解答群の数が空欄の種類に合っているか**（語句・式 4、数値 5、組合せ 7、比較 2〜3）。**5 に揃っていないか**
- **「全て挙げると」の 7 択が本番と同じ順か**（`①`、`②`、`③`、`①と②`、`①と③`、`②と③`、`①と②と③`）
- **複数選択（誤り選び）の問題文に「2 つ選びなさい」があるか**、`answer` が昇順の配列か
- **数値の選択肢が小さい順か**。正解の位置が章の中で散っているか（真ん中ばかりでないか）
- **章の中で 2 択が 2 割を超えていないか**。「全て挙げる」の正解が「全部」に偏っていないか（3 割まで）
- **正しい記述と誤りの記述の長さ・密度がそろっているか**。言い切りが誤答だけにないか
- **「本文で述べた」「前問で求めた」のような参照が無いか**
- **`sectionId` がその問題の内容の本体の節を指しているか**（課目をまたぐテーマは `section-plan.md` §3 の本体）

### 6. 解説

- **正解の理由と、誤答が「なぜ違うか」を書いているか。**組合せと誤り選びは、**記述 1 つずつ正誤と理由**
- **解説の数値・式が問題文と食い違っていないか**
- **教本の本文と食い違っていないか**（語・記号・基準）
- **条番号が合っているか**

### 7. 範囲と重複

- **章の範囲（節）を外れた問題が無いか**
- **同じ章の中で、同じことを 2 回問うていないか**
- **課目をまたいで、同じ問題がほかの章にないか**（空気比、蒸気表、冷凍サイクル、判断基準）
- **問題が使っている語が教本にあるか**（`node scripts/terms.mjs` が、確認問題にあって教本に無い語を挙げる）

## ★ 指摘は「居場所を全部」挙げてください

**1 つの主張は、教本の節の中に 6 つの居場所を持ちます**（本文／表／試験のポイント／よくある勘違い／まとめ／一問一答）。
**その外側に、確認問題・前置き・計算ドリル・ウィジェット・執筆プロンプトがあります。**
`node scripts/echoes.mjs <語>` が居場所つきで出します。

**問題の誤りが教本の誤りから来ているなら、教本の居場所も挙げてください。**
直す側が問題だけ直すと、教本と問題が食い違ったまま残ります。

## 報告の形

**指摘は、次の形で 1 件ずつ書いてください。**

```
### 【重さ】 問題 ID — 一行の要約

- **いまの記述**：（そのまま引用。記述①〜⑥のどれか、前置きかも書く）
- **何が問題か**：（検算の値、照らした条文・年度の大問）
- **正しくは**：
- **同じ主張のほかの居場所**：（教本の節・ほかの問題・前置き・ドリル・プロンプト）
```

| 重さ | 何か |
| --- | --- |
| **重** | **正解が変わる。**誤答が実は正しい／正答が実は誤り／正解が 2 つある／数値が違う／公開問題の写し |
| **中** | 正解は変わらないが、条件が足りず定まりにくい。解説が誤っている。本番の文に近い |
| **軽** | 長さの偏り、言い回し、書式 |

**最後に、次の 4 つを必ず書いてください。**

1. **全問を自分で解いたか**（解いていない問題があれば挙げる）と、**検算した計算の一覧**
2. **確かめたが食い違いが無かった項目**
3. **資料からは確かめられなかった項目**
4. **★ あなたが自信を持てない指摘**

**4 が空の報告は受け付けません。**
