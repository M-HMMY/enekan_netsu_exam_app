## 6. この章だけの釘

### 6-1. 取り違えの型（「よくある勘違い」の中心）

| 取り違え | 書くこと |
| --- | --- |
| **℃ と K** | 体積の増え方 $1/T$、カルノー効率、放射の 4 乗は**絶対温度**。熱流束の温度差だけなら ℃ のままでよい |
| **比熱の差と比** | 差 $c_p-c_v$ は**ガス定数**（理想気体）。比 $c_p/c_v$ は**比熱比**で、差が正なので**必ず 1 より大きい** |
| **熱伝導率と熱伝達率** | 伝導は $\lambda\Delta T/L$（W/(m·K)、厚さで割る）、対流は $h\Delta T$（W/(m²·K)、厚さは無い） |
| **熱抵抗の単位** | 面積を含めた $R=\Delta T/Q$ は K/W。面積 1 m² あたりは m²·K/W。**問題の単位で見分ける** |
| **放射の 4 乗** | 出す量の比は $(T_1/T_2)^4$。**周囲とのやり取り（正味）は $T_s^4-T_a^4$** で、比の形にならない |
| **乾き度** | **質量の割合**。体積の割合ではない（湿り蒸気の体積はほとんどが蒸気） |
| **換算蒸発量** | 実際の吸収熱を **100 ℃ の蒸発熱 2257 kJ/kg** で割る。分母と分子を逆にしない |
| **21/(21 − O₂)** | **完全燃焼・乾き排ガス・乾き理論燃焼ガス量 ≈ 理論空気量**のときの近似（`fc-17` に厳密式）。**湿りの O₂ を入れない。酸素富化空気には 21 のまま使わない** |
| **理論酸素量と理論空気量** | 空気量 ＝ 酸素量 ÷ 0.21（体積）。小問がどちらを聞いているかを読む |
| **粘度の温度変化** | **液体は温度が上がると粘度が下がり、気体は上がる** |
| **風速の 3 乗** | 運動エネルギーは $v^2$、単位時間に通る空気の質量は $v$ に比例するので、**出力は 3 乗**。面積（直径の 2 乗）には 1 乗 |
| **相似則** | 流量 $N$、揚程 $N^2$、軸動力 $N^3$。**同じ機械で、相似な運転点（効率が変わらない）**のとき。**実揚程（静水頭）がある系では、回転速度を下げても動力は 3 乗ほど下がらない** |
| **発熱量の基準** | 高発熱量か低発熱量か。**同じ運転でも低発熱量基準の熱効率のほうが大きく出る** |
| **kWh と MJ** | 1 kWh ＝ 3.6 MJ。**3.6 を落とすと 1 桁以上ずれる** |
| **発電端と送電端** | 送電端は所内で使う電力を引いた値で、発電端より小さい |
| **COP と APF** | COP は 1 つの条件での比。**APF は 1 年を通した能力の合計 ÷ 消費電力量の合計**で、外気温度ごとの運転時間と部分負荷を含む |

### 6-2. 数値

- **公開問題の数値と場面を使わない。**とくに、炉壁の 880 ℃ / 80 ℃ / 0.2 W/(m·K) / 640 W/m²（R7・R8 で表裏に使われた組）、660 ℃ / 60 ℃ / 30 cm、600 K と 400 K、500 K と放射率 0.8、0.2 MPa の 505 / 2706、120 ℃ の 503.8 / 2202、227 ℃ と 27 ℃、O₂ 2.1 %、25 % の富化空気、ブタン、220 MWh と A 重油 50,000 L、240,000 kWh と 45 MJ/m³N、38 % と 100 GWh。**同じ比（1.5 倍の温度比など）も避ける**
- **物性値（蒸気表の値・比熱・σ・発熱量）は例題の中で「…とする」と与える。**蒸気の値は CoolProp（IAPWS-IF97 相当）で取った値を丸めて使う
- **例題の数値はすべて Python で検算する**
- **判断基準の数値（基準空気比、受電端力率の基準など）はこの 6 節に書かない**（工業炉の値は `hu-43`、ほかは告示を取ってから `ea-11`）

### 6-3. 小問の節の作り

- **節ごとに小問の型を 3〜5 個**並べ、それぞれ「与えられるもの → 出すもの → 式 → 代入 → 値 → 解答群での確かめ」を短く通す（`00-common.md` §4 の 7 段のうち「次の空欄へ」は、連鎖しないので「**取り違えたときの値**」に替える）
- **取り違えた式・単位で出る値を、1 節に 1 か所以上見せる**（解答群にはその値が並ぶことが多い）
- **導出は 1〜2 行で根拠だけ**。詳しくは本体の節へリンクする
- **電卓の作法**（`i-3`）：$T^4$ は 2 乗を 2 回、$\sigma T^4=5.67\times(T/100)^4$ で桁を軽くする、途中で丸めない
- **問題文に近づけない。**小問の並び順・言い回し・場面（「ある加熱炉は…」）を写さない。**一問一答は空欄をそのまま問いにしない**（比・数値例・理由で問う）。**試験のポイントとまとめは本文の軸の順**にし、本番の空欄の答えを出題順に並べない
