## レビューで出た型（課目Ⅱで実際に出たもの。書き手にもレビュアーにも渡す）

| 型 | 例 |
| --- | --- |
| **条件の書き落とし** | 「理想気体では」（マイヤー）、「定常で分岐・漏えい・蓄積なし」（連続の式）、「摩擦係数一定なら」（流速の 2 乗）、「閉じた系で体積仕事以外の仕事なし」（$Q_p=\Delta H$）、「両流体とも温度が変化する場合」（向流）、「絶対温度が」（4 乗則）、「同じ管・同じ流体で」（流速の 0.8 乗）、「凝縮温度は同じ」（成績係数の表） |
| **比べ方を書かない** | 断熱と等温の仕事は、同じ圧力比か同じ終状態か、境界仕事か工業仕事かで大小が変わる（κ=1.4 の境界仕事は圧力比 9.36 で逆転） |
| **「別の量」「必ず」の言い過ぎ** | 温度効率・エネルギー効率・有効度 ε は一致する場合がある。熱と仕事は経路で「違い得る」 |
| **呼び名の揺れ** | 流出係数 C と流量係数 α=C/√(1−m²)。「1 より小さい」は C だけ |
| **出典の取り違え** | 送風機の 10 kPa／0.1 MPa の区分は JIS ではなく慣用の分類 |
| **根拠の取り違え** | 可逆の根拠を作動流体のエントロピー（どのサイクルでも 1 周で戻る）に置いた → 熱源を含めた全体のエントロピー生成 |
| **検算の文の符号** | NPSH に大気開放のゲージ圧 0 を入れると「0 に近い」ではなく負になる |
| **表の値** | 「実在の値ではない」と書いた冷媒表の飽和側が R134a の実在値だった |
| **記法の崩れ** | `T_\\infty` が「infty」、`\\dot m` の点が手前の空白に載る（いまは `check-source.mjs` が弾く）。数式の記号の波かっこは描画検査がエラーにする |
| **問われたのに書かれていない** | 課目Ⅲ（10 月 4 日）：分析計の干渉成分、ヘンペル、自然通風の炉内負圧、大気圧式バーナ、水素の燃焼速度の極大の位置、比重 15/4 ℃、流動層の N₂O。**書き手は §7 と要約しか見ないので、空欄の語が落ちる** |
| **章どうしの食い違い** | 燃焼計算の章が「O₂ 計はふつう乾き」と書き、燃焼装置の章は「ジルコニア式は湿り」と警告していた。並行して書かせた章どうしは、レビューで突き合わせる |
| **flow 図の `->`** | flow は 1 行を 1 箱にして矢印を自分で描くので、行頭の `->` が箱の中に文字で出る（`check-source.mjs` が弾くようにした） |
