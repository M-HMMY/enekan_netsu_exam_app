## 6. この章だけの釘

### 6-1. 取り違えの型（「よくある勘違い」の中心）

| 取り違え | 書くこと |
| --- | --- |
| **乾きと湿り** | 燃焼ガス量・濃度は、水蒸気を含めるか（湿り）除くか（乾き）で値が違う。**排ガス分析計の値が乾きか湿りかは計器による**（除湿してから測る方式は乾き、煙道直挿しのジルコニア式は湿り）。**問題文の指定に従う** |
| **体積基準と質量基準** | 気体燃料は燃料 1 m³N あたり、液体・固体燃料は燃料 1 kg あたり。空気の O₂ は**体積で 21 %、質量で約 23 %**（どちらも問題文の値を使う） |
| **m³N** | 0 ℃・101.325 kPa に換算した体積。**H₂O の m³N は、気体として数えた仮想の体積**（0 ℃ では凝縮する） |
| **0.21 で割るか掛けるか** | 理論空気量 ＝ 理論酸素量 ÷ 0.21 |
| **理論燃焼ガス量と実際の燃焼ガス量** | 実際 ＝ 理論 ＋ (m − 1) × 理論空気量。**過剰空気は燃えずにそのまま出る** |
| **近似式の条件** | $m=21/(21-\mathrm{O_2})$ は**完全燃焼で、乾き理論燃焼ガス量 ≈ 理論空気量と見なせるとき**の近似。$m=\mathrm{CO_{2max}}/\mathrm{CO_2}$ も同じ近似。**厳密には $G_{0d}/A_0$ が要る** |
| **不完全燃焼の空気比** | 空気比の分母は**完全燃焼の**理論空気量のまま。CO があると、残っている O₂ のうち CO を燃やすのに要る分（CO の半分）は「余った酸素」ではない |
| **燃料中の酸素** | 理論酸素量から引く（質量組成では $h-o/8$）。**燃料中の窒素・CO₂ は燃えずに燃焼ガスへ移る** |

### 6-2. 式の適用条件を書き落とさない

| 式・主張 | 必ず添える条件 |
| --- | --- |
| 体積比 ＝ モル比 | **理想気体として、同じ温度・圧力で比べたとき** |
| 1 kmol ＝ 22.4 m³N | **理想気体の近似**。問題文の値を使う |
| $h-o/8$（有効水素） | **燃料中の酸素がすべて水素と結合して水になっていると見なす**慣用の扱い |
| $m=N_2/[N_2-3.76(O_2-0.5CO)]$ | **乾き排ガスの分析値で、燃料中の窒素を無視でき（N₂ はすべて空気から）、未燃分は CO だけ**のとき |
| 排ガス熱損失 $G_w c_p(t_g-t_0)$ | **低発熱量基準**なら水蒸気の潜熱は損失に数えない（高発熱量基準なら数える）。**基準温度**（外気温度など）は問題文が決める。比熱は**平均比熱で、体積基準か質量基準か**を燃焼ガス量と揃える |
| 空気比を下げた効果 | **排ガス温度が変わらないと見なす**とき、など比べる条件を書く |
| 燃料の節約率 | **有効に使う熱を同じにし、排ガス以外の損失は変わらない**とき |
| 理論燃焼温度 | **断熱（外へ熱を逃がさない）・解離を無視・平均比熱を与えたとき** |
| 空気予熱器の熱収支 | **漏れと放熱がないとき**。燃料 1 単位あたりの空気量と燃焼ガス量で収支をとる |

### 6-3. 数値

- **公開問題の燃料・組成・数値・場面を使わない。**R8 のプロパン・ブタン混合、R7 の重油、R6 のプロパン熱風発生装置と同じ組成・同じ場面を作らない。**自前の値にする**
- **物性値（平均比熱、発熱量、空気の組成、モル体積）は例題の中で「…とする」と与える。**説明のための値には「本番は問題文の値を使う」と添える
- **例題の数値はすべて Python で検算する。**
- **章を通す燃料を 2 つにする。**
  - **燃料 G**（体積組成の混合ガス）：`fc-14` で理論量 → `fc-16` で空気比 1.20 の燃焼ガス量と O₂ 濃度 → `fc-17` でその O₂ 濃度から空気比を戻す → `fc-18` で同じ燃料が CO を出したとき → `fc-19` で熱損失と空気比 1.10 への改善 → `fc-20` で空気予熱と燃焼温度
  - **燃料 L**（質量組成の重油）：`fc-15` で理論量 → `fc-16` で湿り・乾き → `fc-17` で CO₂ 濃度から空気比
- 判断基準の基準空気比・廃ガス温度の値は書かない（`hu-43` だけ）

### 6-4. 計算の節の作り

- 「式がどこから来るか」「解答群から選ぶ手順」「検算」を分ける

- **式を選ぶ空欄に備えて、取り違えた式（0.21 を掛ける、乾きと湿りを入れ替える、(m−1) を m にする）がどんな値になるかを 1 か所は見せる**
