# エネ管 熱 学習アプリ

**エネルギー管理士試験（熱分野）**の学習アプリです。
教本・確認問題・間隔反復・模試を 1 つにまとめる予定です。

**立ち上げたところです**（2026 年 9 月 29 日）。まだ教本も確認問題もありません。

| | |
| --- | --- |
| 教本 | **まだありません**（章立ては受験案内の出題分野から起こしてあります） |
| 確認問題 | **まだありません**（本番の問題の形に合わせて、作り方から決めます） |
| 計算ドリル | **まだありません** |
| 体験ツール | 5 つ（状態方程式・レイノルズ数・熱抵抗・対数平均温度差・理論空気量） |

## 試験の形

**2026 年 9 月 29 日に、[省エネルギーセンター（ECCJ）](https://www.eccj.or.jp/)の
令和 8 年度（第 48 回）受験案内で確認した内容です。**要項は改訂されるので、受験の前に公式サイトで
確かめてください。

- **熱分野と電気分野から 1 つを選びます。**このアプリは熱分野です。課目Ⅰは両分野で共通です
- **4 課目。**課目Ⅰ エネルギー総合管理及び法規／課目Ⅱ 熱と流体の流れの基礎／
  課目Ⅲ 燃料と燃焼／課目Ⅳ 熱利用設備及びその管理
- **★ 課目の番号と時限の順番が違います。**課目Ⅳが 3 時限、課目Ⅲが 4 時限（最後）です
- **筆記試験（マークシート方式）。**大問の中に空欄がいくつも並び、空欄ごとにマークします
- **合格基準は、各課目とも配点の 60 %。**4 課目すべてが基準以上で合格です
- **課目合格があります。**合格基準以上の課目は 3 年間、受験が免除されます
- **受験資格の制限はありません。**受験手数料は 17,000 円（非課税）
- **年 1 回。**令和 8 年度は 8 月 2 日（日）
- 免状の交付には、**エネルギーの使用の合理化に関する実務 1 年以上**の証明が要ります（合格の前後は問いません）

## 動かす

```
npm install
npm run dev      # 開発サーバ
npm run check    # データの整合性 + 実際に描いてみる検査
npx tsc --noEmit
npm run build
```

デスクトップから起動するショートカットを作る場合：

```
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\make_shortcut.ps1
```

## 方針

- **ランタイム依存は React だけ。**ルータ・Markdown・図はすべて自前
- **外部通信をしない。**学習記録は localStorage のみ。サーバもアカウントもない
- **オフラインで動く**（PWA）
- **合否は「この模試の結果が 6 割に届いたか」までしか出さない**
- **公開問題を原文のまま収録しない。**標準解答も同じ扱いです
